# Placement Management System

A console-based Placement Management System developed using **Java, MySQL, and JDBC**. The project manages student details, company information, and placement applications while automatically checking student eligibility based on CGPA.

## Features

- Add student details
- Add company details
- Apply for a company
- Automatic CGPA-based eligibility checking
- View all students
- View all companies
- View all placement applications
- Store data permanently using MySQL

## Technologies Used

- Java
- MySQL
- JDBC
- VS Code
- MySQL Connector/J
